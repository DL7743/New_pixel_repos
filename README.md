# PixelShop — Консольная CRM-система

Программа для управления заказами и пользователями магазина стикерпаков и постеров. Данные сохраняются в JSON-файл.

## 🚀 Инструкция по запуску

1. Убедитесь, что на компьютере установлен **Python 3.x**.
2. Скачайте или скопируйте файлы `app.py` и `shop.json` в одну папку.
3. Откройте терминал (командную строку) в этой папке.
4. Запустите приложение командой:
   ```bash
python app.py
   ```

## 🛠 Возможности
- Просмотр журнала заказов с автоматическим подтягиванием имен.
- Создание пользователей с проверкой на дубликаты Email.
- Защищенный ввод чисел (программа не падает при ошибках ввода).
- Автоматическое сохранение изменений в `shop.json`.
- Экспорт финансового отчета по клиентам в `report.txt`.
